# C 语言 printf/scanf 格式转换符清单

## 一、常用转换符（转换规格）

| 转换符 | 含义 | 对应参数类型 | printf 示例 | 输出结果 |
|--------|------|-------------|-------------|----------|
| `%d` `%i` | 有符号十进制整数 | `int` | `printf("%d", -42)` | `-42` |
| `%u` | 无符号十进制整数 | `unsigned int` | `printf("%u", 42u)` | `42` |
| `%o` | 无符号八进制 | `unsigned int` | `printf("%o", 64)` | `100` |
| `%x` `%X` | 无符号十六进制（小写/大写） | `unsigned int` | `printf("%x %X", 255, 255)` | `ff FF` |
| `%f` | 十进制浮点数（定点） | `double`（printf 中） | `printf("%f", 3.14)` | `3.140000` |
| `%e` `%E` | 科学计数法 | `double` | `printf("%e", 31415.0)` | `3.141500e+04` |
| `%g` `%G` | 自动选 `%e` 或 `%f` 中较短者 | `double` | `printf("%g", 31415.0)` | `31415` |
| `%a` `%A` | 十六进制浮点数（C99） | `double` | `printf("%a", 1.0)` | `0x1p+0` |
| `%c` | 单个字符 | `int`（字符值） | `printf("%c", 65)` | `A` |
| `%s` | 字符串（以 `\0` 结尾） | `char *` | `printf("%s", "hi")` | `hi` |
| `%p` | 指针地址（实现定义格式） | `void *` | `printf("%p", ptr)` | `0x7ffd...` |
| `%%` | 输出百分号本身 | 无 | `printf("100%%")` | `100%` |
| `%n` | 把已输出字符数写入参数（慎用） | `int *` | — | 不打印内容 |

## 二、长度修饰符（与整型转换符组合）

| 修饰符 | 示例 | 对应类型 |
|--------|------|----------|
| `hh` | `%hhd` `%hhu` | `signed char` / `unsigned char` |
| `h` | `%hd` `%hu` | `short` / `unsigned short` |
| `l` | `%ld` `%lu` | `long` / `unsigned long` |
| `ll` | `%lld` `%llu` | `long long`（C99） |
| `z` | `%zu` | `size_t`（C99，打印 `sizeof` 结果常用） |
| `t` | `%td` | `ptrdiff_t`（C99，指针差值） |
| `j` | `%ju` | `intmax_t`（C99） |
| `L` | `%Lf` | `long double`（仅浮点用） |

## 三、标志符（Flags）

| 标志 | 作用 | 示例 | 输出 |
|------|------|------|------|
| `-` | 左对齐 | `%-5d` | `42   ` |
| `+` | 强制显示正负号 | `%+d` | `+42` |
| 空格 | 正数前留空格 | `% d` | ` 42` |
| `#` | 前缀形式：八进制加 `0`，十六进制加 `0x`，浮点保留小数点 | `%#x` | `0xff` |
| `0` | 用 0 填充宽度 | `%05d` | `00042` |

## 四、宽度与精度

```c++
printf("%8.3f\n", 3.14159);  // "   3.142"：总宽 8，保留 3 位小数
printf("%.2s\n", "hello");   // "he"：字符串最多取 2 个字符
printf("%*d\n", 5, 42);      // "   42"：宽度由参数指定
```


## 五、⚠️ printf 与 scanf 的差异（易错点）

| 类型 | printf | scanf |
|------|--------|-------|
| `float` | `%f` | `%f` |
| `double` | `%f`（自动提升） | **`%lf`** ← 常见错误 |
| `long double` | `%Lf` | `%Lf` |
| `unsigned` | `%u` | `%u` |
| 指针 | `%p` | `%p`（谨慎使用） |

```c++
double x;
scanf("%lf", &x);        // 正确：scanf 读 double 必须用 %lf
printf("%f\n", x);       // 正确：printf 中 %f 即可
```


## 六、C99 推荐的可移植写法（`<inttypes.h>`）

```c++
#include <inttypes.h>
int64_t big = 123456789;
uint8_t  small = 200;
printf("%" PRId64 "\n", big);   // 打印 int64_t
printf("%" PRIu8  "\n", small); // 打印 uint8_t
```


> 💡 **提示**：`%n` 存在安全风险（格式化字符串攻击），现代代码中应避免使用；编译器（如 GCC 的 `-Wformat`）通常会对不匹配的格式符给出警告，建议开启。
